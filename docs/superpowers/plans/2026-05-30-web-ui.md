# Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a hosted form at `prvt.pw/go/FORM_TOKEN` that lets a trusted group create self-expiring short links and download QR codes, without anyone in the group knowing the admin secret.

**Architecture:** Two new Worker endpoints — `GET /go/:token` serves the form HTML (only when token matches `FORM_TOKEN`), and `POST /shorten` validates the form token then creates a link using the existing `makeSlug` logic. The form HTML is a template string in `worker/src/form.js`, with the `qrcode` library bundled inline as a pre-escaped JS string exported from `worker/src/qrcode-src.js`.

**Tech Stack:** Cloudflare Workers (existing), qrcode npm package (MIT) bundled via esbuild into a browser IIFE, vanilla JS form with no external runtime dependencies.

## Task 3: Add /shorten Worker endpoint

**Files:**
- Modify: `worker/src/index.js`

- [ ] **Step 1: Add the /shorten route**

Insert the following block in `worker/src/index.js`, **before** the final `return new Response('Not found'...)` line:

```javascript
    if (request.method === 'POST' && pathname === '/shorten') {
      let body;
      try {
        body = await request.json();
      } catch {
        return new Response('Bad request', { status: 400, headers: BASE_HEADERS });
      }

      const { url, ttl, token } = body;
      if (token !== env.FORM_TOKEN) {
        return new Response('Unauthorized', { status: 401, headers: BASE_HEADERS });
      }
      if (!url || !url.startsWith('https://')) {
        return new Response('URL must start with https://', { status: 400, headers: BASE_HEADERS });
      }

      const slug = await makeSlug(env);
      if (!slug) {
        return new Response('Could not generate slug', { status: 503, headers: BASE_HEADERS });
      }

      const ttlSecs = Number(ttl) || 604800;
      await env.LINKS.put(slug, url, { expirationTtl: ttlSecs });
      await env.COOLOFF.put(slug, '1', { expirationTtl: 7776000 });

      const short = `HTTPS://PRVT.PW/${slug}`;
      const expires = new Date(Date.now() + ttlSecs * 1000).toISOString();

      return new Response(JSON.stringify({ slug, short, expires }), {
        status: 201,
        headers: { ...BASE_HEADERS, 'Content-Type': 'application/json' },
      });
    }
```
